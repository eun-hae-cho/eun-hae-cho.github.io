# Profile icons

ORCID and Google Scholar: Simple Icons, https://github.com/simple-icons/simple-icons (CC0), original SVGs from the develop/icons directory.
LinkedIn: Bootstrap Icons, https://github.com/twbs/icons/blob/main/icons/linkedin.svg (MIT).
All icons use the same 20px display dimensions. All three footer links use profile URLs supplied or confirmed by the portfolio owner. The empty Google Scholar hl parameter is omitted; the supplied user ID is preserved.
